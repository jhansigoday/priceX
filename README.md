# 🛒 PriceX — Smart Price Comparison

PriceX is a web-based **price comparison platform** that allows users to compare product prices across multiple shopping platforms and find the best deal.

### ✨ Features

* 🔍 Product search
* 💰 Multi-platform price comparison
* 🏷️ Best-price identification
* 📱 Responsive UI

### 🛠️ Tech Stack

* React
* TypeScript
* Tailwind CSS
* Vite

### 📌 Note

Due to technical and platform restrictions, **real-time web scraping could not be implemented**, so the current version uses **static product and price data**.

With reliable APIs or permitted real-time data sources, PriceX could be extended into a **fully realistic real-time price comparison platform** with live prices, price tracking, alerts, and more.
